# The menu bar icon

OptionsJourney can run in the background with a small **OJ** icon in the menu bar (Mac) or system tray (Windows), so there's no window to keep open.

Click the icon to see:
- **● Running**, plus any alerts that need attention (for example "Schwab needs you to log in again");
- **Open OptionsJourney:** opens the app in your browser;
- **Open Alerts**, when there are some;
- **Start at login:** starts OptionsJourney whenever you log in to the computer;
- **Keep awake during market hours:** stops the computer going to sleep on weekdays from 9:15 to 4:15 New York time, so syncs (and later, bots) keep running. Also in Settings → This computer;
- **Quit OptionsJourney.**

*Until the app is packaged, start it with `uv run optionsjourney-menubar` in the project folder.*
