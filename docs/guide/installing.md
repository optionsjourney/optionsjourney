# Installing OptionsJourney

*Until there's a downloadable app (planned), OptionsJourney is installed from a copy of its folder.*

## Mac
1. Put the OptionsJourney folder wherever you like, for example in your home folder.
2. Open its **scripts** folder and double-click **Install OptionsJourney.command**.
   - The first time, macOS may say it can't be opened because it's from an unidentified developer. Right-click the file, choose **Open**, then **Open** again.
3. A Terminal window shows the progress. The first install downloads Python and takes a minute or two. Nothing outside your home folder is changed.
4. When it's done, an **OJ** icon appears in the menu bar and the app opens in your browser. The [setup guide](setup.md) takes it from there.

To start OptionsJourney again later, double-click **OptionsJourney.command** in the folder, or tick **Start at login** in the OJ menu.

## Windows
1. Put the OptionsJourney folder wherever you like.
2. Open its **scripts** folder and double-click **Install OptionsJourney.bat**.
   - If Windows SmartScreen warns you, click **More info**, then **Run anyway**.
3. When it's done, an **OJ** icon appears in the system tray and the app opens in your browser.

To start it again later, double-click **OptionsJourney.bat** in the folder.
